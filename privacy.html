SmartMail Privacy Policy

Last updated: 9 October 2026

SmartMail is a personal email app built and used by Luca Brind for his own Gmail accounts. It is not offered to the public.

What data SmartMail uses

SmartMail uses the Gmail API to read, organise, label and send email in the Gmail accounts the user signs in with. It also reads the account's email address so it can show which account is which.

Where data is stored

Email and settings are stored only in the user's own browser on their own device. SmartMail has no server and no database of its own. No email data is sent to the developer or to any third party. Data goes only between the user's device and Google.

How data is used

Data is used only to show, sort, search and send the user's email inside the app. It is not sold, shared, used for advertising or used to train AI models.

Google API Services User Data Policy

SmartMail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Clearing the app's site data in the browser deletes everything SmartMail stored on the device.
